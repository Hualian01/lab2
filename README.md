Este laboratorio se centra en la aplicación de técnicas de análisis estadístico mediante Python. El objetivo es explorar y analizar un conjunto de datos reales a través de estadística descriptiva y métodos de visualización.

Se utilizó el conjunto de datos de vinos de Scikit-Learn para realizar un análisis exploratorio de datos (AED), lo que permitió identificar patrones, distribuciones y propiedades estadísticas de los atributos químicos en muestras de vino.

## Objetivos
- Aplicar conceptos estadísticos a conjuntos de datos estructurados.
- Realizar análisis exploratorios de datos con Pandas.
- Generar estadísticas descriptivas para la interpretación de datos.
- Visualizar distribuciones mediante diagramas de caja.
- Comprender la estructura del conjunto de datos y las relaciones entre variables.

## Conceptos aplicados
- Estadística descriptiva (media, mediana, dispersión).
- Técnicas de exploración de datos.
- Análisis de distribución.
- Detección de valores atípicos mediante diagramas de caja.
- Comprensión de la dimensionalidad de los conjuntos de datos.

## El laboratorio demuestra
- Carga del conjunto de datos Wine desde Scikit-Learn.
- Conversión de la estructura del conjunto de datos a un DataFrame de Pandas.
- Extracción de resúmenes estadísticos de características seleccionadas.
- Cálculo de medianas para variables específicas.
- Identificación de dimensiones y atributos del conjunto de datos.
- Generación de diagramas de caja para detectar variabilidad y valores atípicos.

## Conclusiones
- Los atributos químicos muestran una variabilidad significativa entre las muestras de vino.
- Ciertas características presentan una fuerte dispersión, lo que indica potencial de clasificación.
- Los diagramas de caja revelan valores atípicos que pueden afectar el modelado predictivo.
- Los resúmenes estadísticos proporcionan una comprensión fundamental para las tareas de aprendizaje automático.
